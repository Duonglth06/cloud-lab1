What Is Cloud Computing?

Cloud computing means using computing resources through the internet instead of keeping everything on a personal computer. These resources can include storage, servers, applications, and databases. A cloud provider manages the infrastructure, while users access the services they need through a network. For example, I can store documents online and open them from different devices. In this lab, I use cloud hosting to publish a static website so other people can visit it without accessing my laptop. Cloud computing can make services easier to share and expand, although users still need to consider security, internet access, and possible costs.

Cloud Service Models

Different models provide different levels of management.

IaaS

Infrastructure as a Service

Provides computing infrastructure such as virtual machines, networking, and storage. Users manage the operating system and their applications.

Example: Amazon EC2.

PaaS

Platform as a Service

Provides a managed platform for deploying applications. Developers focus on their code while the provider manages the underlying infrastructure and runtime.

Example: Google App Engine.

SaaS

Software as a Service

Provides a ready-to-use application over the internet. Users access the software while the provider manages its operation and updates.

Example: Google Docs.
